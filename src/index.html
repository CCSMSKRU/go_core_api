Интерактивное тестирование go_core_api

Для проведения тестирования откройте Консоль Разработчика (F12 или Ctrl+Shift+I).

Следуйте инструкциям в консоли браузера.

Основные команды:

  • runTest({...}) - запуск теста с конфигурацией.
  • runNext() - подтверждение выполнения шага (когда тест просит запустить или остановить сервер).

Убедитесь, что библиотека была собрана командой npm run build.
