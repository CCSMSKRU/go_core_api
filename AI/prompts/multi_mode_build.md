### Промпт для реализации мультирежимной сборки и тестирования

**Задача:** Настроить Webpack и подготовить тестовое окружение для поддержки различных режимов использования библиотеки `go_core_api`.

#### 1. Режимы сборки (Webpack)
Необходимо обеспечить корректную работу следующих сценариев:

*   **Браузер (через тег `<script>`):**
    *   Файл: `dist/indexES5.js`.
    *   Формат: UMD или IIFE.
    *   Требование: Экспорт `initGoCoreQuery` в глобальную область видимости (`window`).
    *   Сборка: `npm run buildES5`.

*   **Браузер (TS/ESM import):**
    *   Для использования в React, Vite, Webpack и т.д.
    *   Файл: `dist/index.js` (или отдельный ESM бандл).
    *   Требование: Не должен загрязнять глобальную область, если используется через `import`.

*   **Node.js (CommonJS / `require`):**
    *   Для старых серверов или скриптов.
    *   Файл: `dist/index.node.js` (или аналогичный).
    *   Требование: Использование нативных модулей Node.js (через `externals`), поддержка `require`.

*   **Node.js (ESM / `import`):**
    *   Для современного Node.js окружения.

#### 2. Задачи по конфигурации
1.  **Webpack:**
    *   **Динамический `output`:** Настроить `filename` и `libraryTarget` (UMD для всех, IIFE для ES5 если нужно) в зависимости от `process.env.ES5` и `process.env.TARGET`.
    *   **Babel & TS:** Настроить `babel-loader` так, чтобы при `ES5=true` он использовал соответствующие пресеты и плагины для полной совместимости.
    *   **Externals для Node.js:** Реализовать `getExternals()` в `webpack.config.js`, который корректно исключает нативные модули и зависимости (например, `socket.io-client`) только для `target: 'node'`.
    *   **Entry Points:** Убедиться, что для браузерной сборки используется `index.ts`, а для Node.js, если есть отличия, соответствующая точка входа (сейчас `index.js`).

2.  **Package.json:**
    *   **Скрипты:** Добавить `build:es5`, `build:node`, `build:browser` (ESM) и общий `build:all`.
    *   **Экспорты (Conditional Exports):** Настроить поле `exports` для поддержки `import` и `require` в Node.js, а также браузерных бандлеров.
    *   **Типизация:** Указать путь к `.d.ts` файлам в `types`.

#### 3. Тестирование (Конкретные шаги)
1.  **Браузер (Script):** Создать `tests/manual/test_script.html`, подключить `dist/indexES5.js`, проверить наличие `window.initGoCoreQuery`.
2.  **Node.js (CJS):** Создать `tests/node/test_require.js`, использовать `require('../dist/index.node.js')`, вызвать базовый метод.
3.  **Node.js (ESM):** Создать `tests/node/test_import.mjs`, использовать `import`, проверить работу.
4.  **Автоматизация:** Добавить скрипт в `package.json` для запуска этих тестов после сборки.

**Ожидаемый результат:** Все команды сборки работают, создают соответствующие файлы в `dist`, и каждый файл успешно проходит базовый тест подключения (ping) в своем окружении.
