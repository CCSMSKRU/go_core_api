# Тестирование ccs.go_core_query

В этом каталоге содержатся скрипты и инструменты для тестирования библиотеки в различных средах (Node.js, современные браузеры, ES5).

## Типы тестов

### 1. Node.js (Автоматизированные тесты)

Проверяют корректность загрузки и инициализации библиотеки в окружении Node.js для форматов CommonJS (require) и ESM (import).

**Запуск всех тестов Node.js:**
```sh
npm run test:node
```

**По отдельности:**
- **CommonJS:** `node tests/node/test_require.js` — проверяет `dist/index.node.js`.
- **ESM:** `node tests/node/test_import.mjs` — проверяет `dist/index.js`.

---

### 2. Браузерные тесты (Интерактивные)

Предназначены для запуска в консоли браузера на любой странице, где подключена библиотека (например, `src/index.html`).

**Файл:** `tests/browser_test.js`

**Как запустить:**
1. Откройте страницу с подключенной библиотекой (например, запустив `npm start`).
2. Вставьте содержимое файла `tests/browser_test.js` в консоль разработчика (F12).
3. Используйте функцию `runTest()` с параметрами вашего сервера:
   ```js
   // Тест через WebSocket
   runTest({host: "127.0.0.1", port: 8071, https: false, useAJAX: false, login: "admin", password: "123"});

   // Тест через HTTP (AJAX)
   runTest({host: "127.0.0.1", port: 8071, https: false, useAJAX: true, login: "admin", password: "123"});
   ```
4. Следуйте инструкциям в консоли (скрипт попросит запустить или остановить сервер для проверки реконнекта). Для подтверждения действия вводите:
   ```js
   runNext();
   ```

---

### 3. Ручной тест ES5 (Legacy)

Проверяет работоспособность бандла для старых браузеров.

**Файл:** `tests/manual/test_script.html`

**Как запустить:**
1. Соберите проект: `npm run build:all` или `npm run build:es5`.
2. Откройте файл `tests/manual/test_script.html` в браузере.
3. Страница отобразит статус инициализации глобальной функции `window.initGoCoreQuery`.

---

## Структура каталога

- `node/` — тесты для среды Node.js.
  - `test_require.js` — проверка CommonJS.
  - `test_import.mjs` — проверка ESM.
- `manual/` — ручные тесты.
  - `test_script.html` — проверка ES5 бандла через `<script>`.
- `browser_test.js` — интерактивный сценарий для тестирования логики работы (WS/AJAX, реконнекты).
- `interactive_test.js` — дополнительные интерактивные инструменты тестирования.
