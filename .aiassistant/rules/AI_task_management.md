### Управление задачами и прогрессом (AI/TaskManagement)

Это правило описывает механизм отслеживания прогресса при работе над сложными и длительными задачами.

#### 1. Файл прогресса (current_progress.md)

Для каждой крупной задачи агент должен поддерживать актуальное состояние в файле `AI/current_progress.md`.

*   **Если файла нет**: Создать его при начале новой большой задачи.
*   **Если файл есть**: Ознакомиться с ним в начале сессии, особенно если разработчик просит "продолжить работу по текущему прогрессу".
*   **Обновление**: В конце каждой сессии или после завершения значимых этапов агент должен обновлять статус задач в этом файле.

#### 2. Структура current_progress.md

Рекомендуемая структура файла:
1.  **Название задачи**: Краткий заголовок.
2.  **Цель**: Описание финального результата.
3.  **План реализации**: Список этапов с отметками о выполнении.
4.  **Текущий контекст**: Описание того, на чем остановились в прошлый раз, какие файлы были изменены, какие возникли сложности.
5.  **Следующие шаги**: Конкретные действия для следующей итерации.

#### 3. Передача контекста между агентами

Файл `current_progress.md` является основным связующим звеном между сессиями разных агентов. Он позволяет:
*   Избежать повторного анализа уже решенных проблем.
*   Соблюдать общую архитектурную линию.
*   Давать разработчику четкое понимание текущего статуса без чтения логов чата.

#### 4. Правила взаимодействия и обновления плана

*   **Технические стандарты**: Все действия должны соответствовать техническим стандартам, описанным в `.aiassistant/rules/*.md`.
*   **Принцип подтверждения**: Перед выполнением любых действий по плану агент должен кратко описать, что именно он собирается сделать, и запросить подтверждение у пользователя. Только после получения одобрения можно приступать к реализации.
*   **Детализация плана**: План в `current_progress.md` должен быть максимально подробным. Каждый шаг должен соответствовать одному небольшому действию (например, написание одного метода в одном классе). Это необходимо для пошаговой проверки и уточнения логики.
*   **Реакция на замечания**: Если пользователь вносит замечания или уточнения, агент должен немедленно дополнить или скорректировать план в `current_progress.md` (даже если эти действия относятся к будущим этапам).
*   Все изменения в плане должны быть мотивированы в секции "Текущий контекст" или "Журнал изменений".
